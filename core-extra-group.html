Controlled vocabularies used in these forms

          

            Choose a vocabulary in a field, then type at least two characters in
            the term box: matching concepts appear in a drop-down list. Picking
            one fills the term, term URI, code and vocabulary. The profile
            accepts at least one of: vocabulary name, vocabulary URI, term URI
            or code; term URIs are preferred.

Lookup settings (edit in the page script)

        

        

          Direct browser calls only work if the vocabulary server allows
          requests from your page (CORS). If a lookup fails, the form says so
          and you can still type the term and paste its URI. For production, set
          CONFIG.proxy to your own endpoint (for example a DSpace
          or Nginx route). The page then calls
          {proxy}{sourceId}?q=text&limit=25 and expects a JSON
          list of {"uri","label","code","note"}. The server can
          cache results, hold local copies of FISH and PeriodO, and add the
          Getty attribution line.
